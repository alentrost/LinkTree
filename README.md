# LinkTree

Preprosta in moderna landing page za prikaz posameznikovih povezav do socialnih omrežij in profilov.

## Opis projekta

Ta projekt je vizualno čist, minimalističen LinkTree stilni seznam povezav z enim glavnim profilom in gumbi za dostop do različnih platform. Stran je izdelana v enem HTML datoteki in uporablja CSS za oblikovanje, animacije in odzivnost.

Na prvi pogled prikazuje profil:

- Alen Trošt
- @alentrost
- povezave do Snapchat, Instagram, TikTok, Facebook in LeetCode

## Funkcije

- minimalistični dizajn z zeleno, bež in temno zeleno paleto
- odzivna postavitev za manjše in večje zaslone
- gumbi z ikonami in hover efekti
- povezave v novem zavihku z rel="noopener noreferrer"
- en sam HTML dokument za hitro uporabo in enostavno urejanje

## Struktura projekta

- index.html — glavna HTML struktura in CSS


## Tehnologije

- HTML5
- CSS3
- SVG ikone
- brez zunanjih bibliotek
